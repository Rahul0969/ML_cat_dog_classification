# Task 1 Summary: Cats vs Dogs Image Classification

**Problem.** The goal is to classify photographs as a cat (0) or a dog (1), a binary image-classification task.

**Dataset.** About 25,000 labeled JPEG images sit in a single folder, `data/train/`. Because there are no class subfolders, labels are inferred from filenames (`cat.*` → 0, `dog.*` → 1) and stored in a Pandas DataFrame. Corrupt files are detected and removed.

**Preprocessing.** Each image is read, decoded to RGB, resized to 128×128 and normalized to the 0–1 range. The data is split 80/20 into training and validation sets, stratified by class with a fixed seed of 42.

**Data pipeline.** Instead of loading every image into memory, a `tf.data` pipeline reads images lazily from file paths. It maps the loading function in parallel, batches 32 images at a time and prefetches the next batch while the model trains. Random flips, rotations and zooms are applied only during training to help the model generalize.

**Model.** MobileNetV2 pretrained on ImageNet acts as a frozen feature extractor, followed by global average pooling, dropout and a single sigmoid output neuron. It is compiled with the Adam optimizer and binary cross-entropy loss.

**Training.** The classifier head is trained first with early stopping on validation loss. The last 20 base layers are then optionally fine-tuned at a learning rate of 1e-5, and the change is kept only if validation loss improves.

**Evaluation.** The validation set is scored with accuracy, precision, recall, F1-score, a classification report and a confusion matrix. Training curves, metrics files and plots are saved to `results/`.

**Predictions.** The notebook shows labeled predictions with confidence for 12 validation images and includes a single-image prediction function. The trained model is saved in Keras format and reloaded to verify it works.

**Conclusion.** The project delivers a memory-efficient, reproducible transfer-learning pipeline. All numerical results are generated by running the notebook and saved to `results/metrics.json`.
